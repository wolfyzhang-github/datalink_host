下载说明

设备数据通过 FTP 协议下载。

建议使用随设备提供的 FileZilla 软件：
1. 打开 FileZilla。
2. 主机输入 10.2.16.214，端口输入 21。
3. 用户名输入 Semi，密码保持为空。
4. 点击快速连接，进入设备数据目录。
5. 选择需要下载的数据文件，拖拽到本地目录完成下载。
6. 下载结束后断开 FTP 连接。
